UNREAD Uploader — Privacy Policy

Last updated: November 6, 2026

UNREAD Uploader is a private tool used only by the owner of the UNREAD YouTube channel to upload and schedule the channel's own videos. It is not offered to the public, and no other people sign in to it.

What data it uses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos, set thumbnails, titles and descriptions, schedule publish times, manage the channel's playlists, and read the channel's own video list and public statistics.

How the data is stored

The OAuth sign-in token is stored only in the owner's private, encrypted storage (the owner's computer and encrypted GitHub Actions secrets). No data is sold, shared with third parties, or used for advertising.

Google API Services

UNREAD Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: contact the channel through the UNREAD YouTube channel.
